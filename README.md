# MAC URBAN CIVIL CONSTRUCTION — Free Website

This is a static HTML/CSS/JS website designed for:
macurbancivil.com.au

## Cost
The website files themselves have no recurring software cost.

A free hosting route is GitHub Pages. GitHub Pages supports custom domains on GitHub Free public repositories and HTTPS. See:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages

## Publish with GitHub Pages

1. Create/login to a GitHub account.
2. Create a PUBLIC repository named `mac-urban-civil`.
3. Upload `index.html`, `styles.css`, `script.js`, and `CNAME`.
4. In the repository go to Settings → Pages.
5. Choose "Deploy from a branch", select `main`, and save.
6. Add custom domain: `macurbancivil.com.au`.
7. In GoDaddy DNS, point the root domain to GitHub Pages using the four A records in the official GitHub documentation, and point `www` to your GitHub Pages address.
8. Enable HTTPS after GitHub provisions the certificate.

IMPORTANT:
Do not delete existing MX records if you use your GoDaddy email. Only change the web-related DNS records after checking your current DNS setup.
